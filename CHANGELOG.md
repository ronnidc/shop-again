## [1.0.0] - 2026-10-16

### Added

- Notes on a web shop: a verdict, a set of fixed reasons, an optional note and a date. A shop holds several dated entries.
- A banner at the top of a shop with notes: a full bar the first time in a browser session, after that a thin line with a tab placed in a gap of the shop's own header. Good news gets out of the way by itself.
- The verdict as a badge on the toolbar button.
- An overview page with every shop, search, a filter, adding a shop by its address, settings, and JSON export and import.
- A right-click menu that opens the notes for the current page or for a link.
- A note in progress survives the popup closing, for the rest of the browser session.
- Site access one shop at a time, given once for every site, or never, chosen in the settings. Access is given back when a shop's last note is deleted.
- English and Danish.
- A footer on the overview page with the version and the two ways to send feedback, by mail or as a GitHub issue, with the version and the browser filled in.
